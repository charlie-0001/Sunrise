# About
Sunrise is a Roblox game created by charlie-0001 on GitHub and beecolonthree on Roblox. This is a solo project with very minimal use of AI. It is an extremely difficult 3D platformer featuring a variety of platforming mechanics like falling platforms, kill bricks, music zones, lighting changers, spinning platforms, turrets, wall bounces, etc. This game is in the obby genre on Roblox, and a more specific subgenre named "tower obbys". Tower obbys are typically ~20 minute long ascending platforming challenges that are split into 10 floors with no checkpoints.

For any onlookers curious about the progress of this codebase, I will try to push out my progress at least once per week, which you can check in the commit history.
